# URC@UNC Website

The official website for the Undergraduate Research Conference at the University of Northern Colorado.

Built with [Next.js](https://nextjs.org) and deployed via GitHub Pages.

## Development

```bash
cd urc-website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

## Build & Deploy

```bash
npm run build
```

The site is automatically deployed to GitHub Pages via the `.github/workflows/deploy.yml` workflow on push to `main`.

## Domain

The site is served at [uncurc.com](https://uncurc.com).
